# Demo Accounts

Стартовые учетные записи для демонстрации:

| Роль | Логин | Пароль | Доступ |
| --- | --- | --- | --- |
| Админ | `admin` | `admin12345` | Видит все результаты, все группы, аналитику и аудит |
| Преподаватель | `teacher1` | `teacher12345` | Видит только назначенные ему группы |

Демо-группы и студенты:

| Группа | Студенты |
| --- | --- |
| `Группа A` | `user1`, `user2`, `user3`, `user4` |
| `Группа B` | `user5`, `user6`, `user7`, `user8`, `user9`, `user10` |
| `Группа C` | `user11`, `user12` |

Правило привязки результатов из Unity:

- если студент сохраняет ник в игре как `user1`, результат будет связан со студентом `user1`;
- `teacher1` видит три группы: `Группа A`, `Группа B`, `Группа C`;
- если в Unity приходит неизвестный ник, результат сохраняется, но остается неподвязанным к студенту.
